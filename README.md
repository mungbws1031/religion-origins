# 유대교·조로아스터교·불교·그리스도교의 기원과 접점

유대교·조로아스터교·그리스도교가 언제 어디서 시작됐는지 비교하고, 불교를 포함한 네 전통이
역사 속에서 실제로 접촉한 지점(확실한 접촉 vs 학계에서 논쟁 중인 영향 관계)을 타임라인·관계도·연표로 정리한
단일 HTML 페이지입니다.

`index.html`을 브라우저로 열면 바로 볼 수 있고, 별도 빌드 과정은 없습니다.

## 담긴 내용

- **기원 타임라인** — 유대교·조로아스터교·그리스도교의 시작 시점 비교
- **항목별 비교표** — 창시자·시작 시점·장소·정치적 배경·경전·확산 경로
- **개략도** — 세 전통 발상지 사이의 지리적 거리
- **접점 관계도** — 불교를 포함한 네 전통이 이후 역사에서 어떻게 얽혔는지
- **접점 연대기** — 기원전 1500년경부터 기원후 325년까지 상세 연표

각 절 하단에 학계 연대 논쟁·증거 수준에 대한 유보 사항을 밝혀두었습니다.
